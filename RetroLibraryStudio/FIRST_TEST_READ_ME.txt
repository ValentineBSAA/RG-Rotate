Retro Library Studio v1.5.4 — Two-minute Windows acceptance

1. Extract into NEW folder (do not overwrite prior app or virtual NAS card).
2. Launch Start_Retro_Library_Studio.bat. Confirm v1.5.4 and existing NAS workspace.
3. Open Clock Tower cover search. Select USA/Japan and WAIT a moment: the COVER should appear under results automatically. Switching selection should change the preview. Confirm before Use selected cover.
4. Back in My Games, RIGHT-CLICK the Clock Tower card. Choose "Convert to verified CHD + tidy PSX folder".
5. Read confirmation. Only after CHDman verifies new CHD will original CUE/BIN files move to the named " - Conversion Backups" folder alongside the virtual card, not be deleted.
6. Wait for completion. Confirm Clock Tower format badge changes BIN/CUE -> CHD, PSX folder has just one CHD, cover unchanged, recovery backup contains original CUE and both BIN tracks.
7. Optional: right-click IMG entry; try converting only if it has safe single-track raw CD layout. CloneCD CCD/IMG/SUB and ambiguous IMG are REFUSED with explicit error rather than discarded.
8. Try copy to a disposable practice folder and verify SHA-256. Do not format the real microSD.

Source/mock tests and Windows GUI tests do NOT prove genuine CHDman can handle your actual disc. Please report the exact dialog/error if conversion fails. Do not manually delete backups until game plays correctly.
